# ✈️ Sky Search – Flight Search Engine

Sky Search is a responsive flight search engine built with modern web technologies.  
It focuses on fast search, real-time filtering and live price visualization to help users make informed travel decisions.

---

## 🚀 Features

- Flight search with origin, destination, dates and passengers
- Real-time flight results
- Advanced filtering (price range, number of stops, airlines)
- Live price trend visualization
- Fully responsive design (desktop & mobile)

---

## 🛠 Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **API:** External Flight Search API (Test Environment)

---

## 📦 Installation & Setup

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/sarajdhakal/sky-search.git
```

### 2️⃣ Navigate to the Project Directory
```bash
cd sky-search
```

### 3️⃣ Install Dependencies
```bash
npm install
```

### 4️⃣ Run the Development Server
```bash
npm run dev
```

### The app will be available at:
```bash
http://localhost:3000
```
